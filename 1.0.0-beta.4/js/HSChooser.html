HSChooser

Type

A keyboard-driven floating chooser panel.

Create via hs.chooser.create(). Configure choices, set callbacks, then call .show().

Choice format

Each choice is a plain object with required text and optional subText, image, valid, and contextMenu fields. All other fields are passed through to the onSelect callback unchanged. Set contextMenu: false on a choice to show no context menu on its row.

{
  text: "Open Safari", subText: "com.apple.Safari",
  image: HSImage.fromAppBundle("com.apple.Safari"), valid: true, myData: 42
}

Context menu

A single right-click menu, set with contextMenu, is shared by every row (except choices with contextMenu: false). When the user picks one of its entries, onContextMenuSelect is called with the row's choice and the menu entry.

chooser.contextMenu = [
  { title: "Open", id: "open" },
  { type: "divider" },
  { title: "Copy bundle ID", id: "copy" }
]
chooser.onContextMenuSelect = (choice, menuItem) => {
  if (menuItem.id === "copy") hs.pasteboard.writeString(choice.subText)
}

Keyboard shortcuts

  • Return — confirm selection
  • Escape — dismiss (calls onSelect with null)
  • ↑ / ↓ — move through results
  • Ctrl-N / Ctrl-P — move through results (alternative to ↑ / ↓)
  • Page Up / Page Down (or Fn-↑ / Fn-↓) — move through results a page (visibleRows rows) at a time
  • Home / End (or Fn-← / Fn-→) — jump to the first / last result
  • Cmd-1 ... Cmd-9, Cmd-0 — instantly select one of the first ten results

frame

HSRect

The chooser panel's frame on screen, in the same coordinates as hs.window and hs.screen (y = 0 at the top of the primary screen, increasing downwards).

onSelectionChange

function | null

Called when the selected row changes while the chooser is visible, or null to remove the handler.

Use this to show something that depends on the selected row, such as a preview, and keep it up to date as the user moves through the rows.

The arguments are the new selectedRow and the row object (same shape as onSelect), or null for the item when no rows match the query. It is called once when the chooser is shown, then whenever the selection moves to a different row, or the row it is on changes to a different choice: arrow keys, Page Up/Down, Home/End, a click, a new query, new choices, or setting selectedRow from JavaScript.

Hammerspoon 2/Modules/hs.chooser/HSChooser.swift:379

contextMenu

any[]

The right-click menu shown for every row (default: [], no menu).

Each entry is either { title: "..." } for a menu item, or { type: "divider" } for a separator. Any other fields on an entry (e.g. an id) are passed back to onContextMenuSelect unchanged, so one handler can tell the entries apart.

A menu item can show a keyboard shortcut with a shortcut field: a string of modifier symbols (⌘ ⇧ ⌥ ⌃) followed by one key, as the menu shows it ("⇧⌘C", or just "O" for no modifiers), or an object with the modifiers and key spelled out ({ mods: ["cmd", "shift"], key: "c" }). Modifier and key names are the same as for hs.hotkey.bind().

A menu shortcut is not a system-wide hotkey, nor a shortcut for the chooser: pressing it chooses the item only while the context menu is open, and does nothing while it's closed.

Rows whose choice has contextMenu: false show no menu, e.g. for a "Clear history" row.

Hammerspoon 2/Modules/hs.chooser/HSChooser.swift:405

onContextMenuSelect

function | null

Called when the user picks an entry from the contextMenu, or null to remove the handler.

choice is the row that was right-clicked (same shape as onSelect's argument) and menuItem is the contextMenu entry that was picked, with any custom fields intact. The chooser stays open.

setChoices(choices) -> HSChooser

Set the choices list. Pass a static array or a function:

  • Array — the chooser filters it automatically as the user types.
  • Function — called with the current query string on every refreshChoices() and on show. The function is responsible for filtering; the chooser displays all items it returns.
