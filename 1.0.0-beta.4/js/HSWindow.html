HSWindow

Type

Object representing a window. You should not instantiate these directly, but rather, use the methods in hs.window to create them for you. Note that this type uses private macOS APIs

Move and resize the window, reporting whether it succeeded

moveToSpace(space) -> Promise<void>

Moves this window to another space, without switching to it. This works for any app's windows, and doesn't use Mission Control.

Only windows on a desktop can be moved, and only to a desktop - not to or from a fullscreen space. Windows set to appear on every space can't be moved either.

Declaration
moveToSpace(space) -> Promise<void>
Parameters
Name Type Description
space HSSpace The desktop to move the window to
Returns
Promise<void>
A Promise that resolves once the window is on that space, or rejects with the reason it couldn't be moved
Example
const desktops = hs.screen.main().spaces.filter(s => s.type === "desktop")
hs.window.focusedWindow().moveToSpace(desktops[desktops.length - 1])

focus() -> boolean

Focus this window

The window becomes its application's main window, and the application is brought to the front with only this window raised. The application's other windows keep their place in the stacking order.

The application finishes coming to the front after this returns, and some applications then bring a different window forward, so this makes the window main again 0.3 seconds later. That is skipped if another of the application's windows has been chosen in the meantime, or if focus() is called again.

Declaration
focus() -> boolean
Returns
boolean
true if the window was made main and its application was brought to the front. The window may not be the focused window yet; check hs.window.focusedWindow() after a short delay if it matters.
Example
const wins = hs.window.allWindows()
wins[0].focus()

windowsToEast(options) -> HSWindow[]

The windows to the right of this one, nearest first

Windows straight ahead are preferred to nearer windows off to the side.

Declaration
windowsToEast(options) -> HSWindow[]
Parameters
Name Type Description
options optional object How to choose the windows
windows optional HSWindow[] The windows to choose from, e.g. those allowed by a window filter. Defaults to every window on screen. Windows that aren't on screen are always ignored
frontmost optional boolean true to put windows that can be seen before windows hidden behind others
strict optional boolean true to only consider windows within 45° of the direction, rather than anywhere on that side of this window
Returns
HSWindow[]
The windows to the right of this one, nearest first
Example
const next = hs.window.focusedWindow()?.windowsToEast()[0]
if (next) console.log("Next window east: " + next.title)

snapshot(keepTransparency) -> Promise<HSImage>

Capture the current on-screen contents of this window as an image.

Requires Screen Recording permission.

Declaration
snapshot(keepTransparency) -> Promise<HSImage>
Parameters
Name Type Description
keepTransparency optional boolean Whether to preserve the window's alpha channel. If false (the default), transparent regions are filled with an opaque black background.
Returns
Promise<HSImage>
Resolves with the captured image, or rejects if the capture fails (e.g. permission denied, or the window could no longer be located).
Example
const win = hs.window.focusedWindow()
win.snapshot().then(img => img.saveToFile("/tmp/window.png"))

Returns a plain object describing this window, for JSON serialisation

Declaration

Returns
{[key: string]: any}
