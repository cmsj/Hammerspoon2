hs.bluetooth

Module

Inspect, connect to and scan for Bluetooth devices, and watch them connect and disconnect.

The module offers two kinds of object, because macOS identifies them in two different ways:

  • HSBluetoothDevice: a device macOS knows by its Bluetooth address, such as headphones, a keyboard or a mouse paired with this Mac. These have battery levels and system-wide connect/disconnect events.
  • HSBluetoothPeripheral: a Bluetooth Low Energy (BLE) peripheral, found by scan(), which Hammerspoon can connect to itself to read and write its GATT characteristics. macOS gives these a UUID identifier instead of revealing their address.
hs.bluetooth.pairedDevices().forEach(d => console.log(d.name + " " + d.address))

hs.bluetooth.connectedDevices()
    .filter(d => d.batteryLevel !== null)
    .forEach(d => console.log(d.name + ": " + d.batteryLevel + "%"))

hs.bluetooth.on('connected', d => console.log(d.name + " connected"))
hs.bluetooth.on('powerChanged', on => console.log("Bluetooth is " + (on ? "on" : "off")))

const nearby = await hs.bluetooth.scan({ seconds: 5 })
nearby.forEach(p => console.log((p.name ?? p.identifier) + " " + p.rssi + " dBm"))

macOS asks the user for Bluetooth permission the first time this module talks to Bluetooth. Use hs.permissions.checkBluetooth() to see whether it has been granted.

Types

This module provides the following types:

  • HSBluetoothDevice
  • HSBluetoothPeripheral

Scans for BLE peripherals nearby. Only one scan can run at a time. Each peripheral found is also delivered to `'discovered'` listeners (see `on()`) as soon as it's seen.

hs.bluetooth.inquiry(options) -> Promise<HSBluetoothDevice[]>

Searches for discoverable classic Bluetooth devices nearby, such as headphones in pairing mode. Only one search can run at a time. This interrupts the audio of connected Bluetooth headphones while it runs.
Declaration
hs.bluetooth.inquiry(options) -> Promise<HSBluetoothDevice[]>
Parameters
Name Type Description
options [String: Any] An object with `seconds` (number, default `10`, at most `255`): how long to search for
Returns
Promise<HSBluetoothDevice[]>
A Promise resolving to the devices found when the search ends, or when `stopInquiry()` is called. Rejects if a search is already running, the options are invalid, or the search fails
Example
