HSCalendarEvent

Type

An event from a calendar, as returned by hs.eventkit.events() and its relatives.

Each property is read from the underlying calendar event when you access it, so fetching many events is cheap even when you only look at a few of their properties. An event is a snapshot: if it changes in Calendar after you fetched it, fetch it again to see the change.

Don't create these yourself; they come from hs.eventkit.

  • Example:
hs.eventkit.eventsToday().forEach(e => {
    console.log(e.startDate.toLocaleTimeString() + " " + e.title + (e.location ? " @ " + e.location : ""))
})

Properties

string

The event's identifier on this Mac.

Every occurrence of a repeating event has the same id, so use it together with occurrenceDate (or startDate) to tell occurrences apart.

toJSON() -> {[key: string]: any}

Returns a plain object holding all of the event's properties, for JSON serialisation.

JSON.stringify() calls this automatically, so you rarely need to call it yourself.
