HSUnixDatagramSocket

Type

A Unix domain datagram socket, created by hs.socket.createUnixDatagram().

A Unix domain datagram socket exchanges messages with other programs on this Mac through a socket file. Each message arrives whole, as one "data" event. Other programs can only send to it once it has been bound to a path with bind(), which creates the socket file there.

This is what tools such as Karabiner-Elements' send_user_command send to.

  • Note: macOS limits datagrams sent by other programs to 2048 bytes unless they raise their send buffer size (see sysctl net.local.dgram.maxdgram). This socket raises its own, so it can send and receive up to 65536 bytes.

Do not instantiate HSUnixDatagramSocket directly - use hs.socket.createUnixDatagram().

bind(path) -> HSUnixDatagramSocket

Binds the socket to a path, creating a socket file there that other programs can send datagrams to. Call it before `connect()` or sending. A stale socket file left at the path by a socket that has gone is replaced, but binding fails if another socket is still using it. `close()` removes the socket file.
Declaration
bind(path) -> HSUnixDatagramSocket
Parameters
Name Type Description
path string The path to create the socket file at, at most 103 bytes long, e.g. `"/tmp/hammerspoon.sock"`.
Returns
HSUnixDatagramSocket
The socket, for chaining.
Example
// Receive Karabiner-Elements' send_user_command messages
globalThis.karabiner = hs.socket.createUnixDatagram().setCallback((event, sock, data) => {
    if (event === "data") console.log(JSON.parse(hs.socket.decodeText(data)).key)
}).bind("/tmp/hammerspoon-karabiner.sock").receive()
