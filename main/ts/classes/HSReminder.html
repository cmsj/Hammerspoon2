    Class HSReminder

    A reminder from the Reminders app, as returned by hs.eventkit.incompleteReminders() and its relatives.

    Each property is read from the underlying reminder when you access it. A reminder is a snapshot: if it changes in Reminders after you fetched it, fetch it again to see the change.

    The properties are read-only; change a reminder with update(), which saves the change straight away, and delete it with remove().

    Don't create these yourself; they come from hs.eventkit, and hs.eventkit.createReminder() makes new ones.

    ReadonlyalarmDates

    alarmDates: Date[]

    When the reminder's alerts go off. Only alerts at a set time are listed; Reminders can also have alerts for arriving at or leaving a place, which update() leaves alone.

    A due date doesn't produce a notification by itself: add an alert for that.

    update

    • update(changes: Record<string, any>): HSReminder | null

      Changes some of the reminder's properties and saves the change.

      changes can hold any of these keys; the properties it leaves out are left as they are:

      • title (string)
      • notes, url (string, or null to clear)
      • dueDate (Date, or null to clear). Keeps the reminder's isAllDay unless changes sets that too; clearing the due date also clears isAllDay.
      • isAllDay (boolean): true makes the reminder due on its due date's day, rather than at its time. Needs a due date.
      • priority ("none", "low", "medium" or "high")
      • isCompleted (boolean), which also sets or clears completionDate
      • alarmDates (array of Date): replaces the reminder's timed alerts; [] removes them
      • listID (string): moves the reminder to another list

      If anything in changes is invalid, or the change can't be saved, this throws and the reminder is left as it was.

      Parameters

      • changes: Record<string, any>

        The properties to change

      Returns HSReminder | null

      The reminder, for chaining

      Throws

      Throws an Error on failure; wrap calls in try/catch to handle it.
