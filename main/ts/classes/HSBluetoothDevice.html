    Class HSBluetoothDevice

    A Bluetooth device macOS knows: one paired with this Mac, or one found by hs.bluetooth.inquiry(). Obtain devices from the hs.bluetooth module; do not instantiate them directly. A device is identified by its address, and the same device is returned as the same object for as long as you hold on to it. Bluetooth Low Energy (BLE) peripherals found by hs.bluetooth.scan() are HSBluetoothPeripheral objects instead. A paired device that also speaks BLE can give you its peripheral with lowEnergyPeripheral(), e.g. to read its GATT characteristics.

    Battery levels

    hs.bluetooth.connectedDevices().forEach(d => {
       if (d.batteryLevel !== null) console.log(d.name + ": " + d.batteryLevel + "%")
    })

    ReadonlybatteryLevel

    batteryLevel: number | null

    The device's battery level as a percentage, or null if macOS doesn't know it. This is what macOS itself reports: for Apple's Magic accessories from the system, and for AirPods and Beats from what macOS last heard from them. For earbuds it is the lower of the two buds; see batteryLevels for each one. For a device that reports its battery over BLE instead, read it with lowEnergyPeripheral() and readBatteryLevel().

    ReadonlybatteryLevels

    batteryLevels: Record<string, number> | null

    The individual battery levels of a device with several batteries, such as earbuds and their case, or null if it has only one (or none is known). The object has any of left, right and case, each a percentage.

    lowEnergyPeripheral

    • lowEnergyPeripheral(): Promise<HSBluetoothPeripheral | null>

      Finds the BLE peripheral of a connected device that also speaks Bluetooth Low Energy, such as a Magic Keyboard or a heart-rate strap, so you can use its GATT services. macOS doesn't link a paired device to its BLE side, so this looks for the BLE peripheral connected to the Mac with the same name. It rejects rather than guess if several have that name, and resolves to null if none does (e.g. the device doesn't use BLE, or it was renamed after pairing). The peripheral still needs connect() before its GATT methods can be used.

      Returns Promise<HSBluetoothPeripheral | null>

      A Promise resolving to the device's peripheral, or null if it has none. Rejects if the device isn't connected, several peripherals match, or Bluetooth is unavailable
