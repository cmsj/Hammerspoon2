    Class HSWindowFilter

    A window filter: a set of rules choosing some of the windows on the system.

    Get the windows it allows with windows(), or listen for windows being created, moved, focused etc. with on(). Create one with hs.windowfilter.create().

    Events

    Listeners are called with the window, its application's name, and the event's name. They're only told about windows the filter allows, or has just stopped allowing (so they hear why it stopped).

    • windowCreated, windowDestroyed. A destroyed window has gone, so only its id can still be read (and its application's name is passed to the listener).
    • windowMoved: moved or resized, including going fullscreen
    • windowFullscreened, windowUnfullscreened
    • windowMinimized, windowUnminimized
    • windowHidden, windowUnhidden: its application was hidden or unhidden
    • windowVisible, windowNotVisible: it's visible when it's neither minimized nor hidden
    • windowInCurrentSpace, windowNotInCurrentSpace: whether it's on a Space currently shown. Minimized and hidden windows count as being in every Space.
    • windowOnScreen, windowNotOnScreen: whether it's actually on screen: visible, and in a Space currently shown
    • windowFocused, windowUnfocused
    • windowTitleChanged

    Five more events are about the filter's set of allowed windows:

    • windowAllowed: a window is now allowed. Emitted before any other event about it, e.g. before windowCreated for a new window.
    • windowRejected: a window is no longer allowed, or was destroyed. Emitted after the events that caused it.
    • hasWindow: the filter allows a window, having allowed none
    • hasNoWindows: the filter allows no windows any more. The listener gets the last one.
    • windowsChanged: the set of allowed windows changed. The listener gets one of the allowed windows, or null if there are none.

    Moves, resizes and title changes are reported once the window has stopped changing for a moment, so dragging a window emits one windowMoved, not hundreds.

    rules: any

    This filter's rules, as an object hs.windowfilter.create() and setRules() accept, or null for a filter made from a function

    sortOrder

    sortOrder: string

    How windows() sorts windows when not told otherwise: "focusedLast" (most recently focused first, the default), "focused", "createdLast" (newest first) or "created". Windows that existed before Hammerspoon started watching count as older than any created since, in order of their IDs, and as focused in their order on screen, front to back.
