    Class HSUDPSocket

    A UDP socket, created by hs.socket.createUDP(). A UDP socket can send datagrams to any host, or be connected to a single peer, and can receive datagrams once it has a local port: either one chosen with bind(), or one the system assigns when it first connects or sends. IPv4 and IPv6 are both supported, using a separate system socket for each. Do not instantiate HSUDPSocket directly - use hs.socket.createUDP().

    Methods

    bind

    • bind(port: number, address?: string | null): HSUDPSocket

      Binds the socket to a local port, so it can receive datagrams sent to that port. Call it before connect() or sending. By default the socket binds on all network interfaces. Pass one of this Mac's IP addresses to bind only to that address (and so only to the interface that has it). Use hs.network.addresses() to find an interface's addresses. If the interface's address can change (e.g. it comes from DHCP), watch State:/Network/Interface/<name>/IPv4 with hs.network.configurationWatcher() and bind again when it does.

      Parameters

      • port: number

        The UDP port to bind to, or 0 to let the system choose one (see localPort).

      • Optionaladdress: string | null

        A local IPv4 or IPv6 address to bind to, e.g. "127.0.0.1" or "192.168.1.20". Defaults to all addresses.

      Returns HSUDPSocket

      The socket, for chaining.

      Remarks

      A socket bound to an address only uses that address's family (IPv4 or IPv6), and doesn't receive broadcasts

      Returns HSUDPSocket
