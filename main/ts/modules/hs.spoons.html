    Namespace spoons

    Load, install and update Spoons - packaged, reusable pieces of configuration. Spoons live in the Spoons directory inside your config directory. Every Spoon you load is also available on hs.spoons under its name, so hs.spoons.load("Greeter") makes hs.spoons.Greeter available to the rest of your config. That's why a Spoon can't be named after one of this module's own methods or properties. Spoons can be installed from any GitHub repository ("owner/repo"), or from a zip file at any https:// URL. There's no central list of Spoons: you choose where each one comes from, so only install Spoons from sources you trust. Pin the version you install with ref (a GitHub tag or commit) or sha256 (for a zip URL), and nothing changes until you choose to.

    Quick start

    // Installs Greeter the first time this runs, then loads it, configures it and starts it
    hs.spoons.use("Greeter", {
       source: "jane/hs2-spoons",
       ref: "v1.2.0",
       config: { message: "Time for a break!" },
       start: true
    })
