    Namespace eventkit

    Read calendar events, and read and change reminders, from the macOS Calendar and Reminders databases (EventKit).

    Events need full access to calendars: call hs.permissions.requestCalendars() to ask for it, and hs.permissions.checkCalendars() to see whether it has been granted. Reminders need access to reminders, from hs.permissions.requestReminders() and hs.permissions.checkReminders(). Every method here throws (or, for one that returns a Promise, rejects) while the access it needs hasn't been granted.

    Events are HSCalendarEvent objects, and reminders are HSReminder objects.

    Finding meeting links for today

    hs.eventkit.eventsToday().forEach(e => {
        const text = [e.location, e.notes, e.url].join(" ")
        const link = text.match(/https://[\w.-]*(zoom\.us|teams\.microsoft\.com)/\S+/)
        if (link) console.log(e.title + ": " + link[0])
    })

    Adding a reminder and ticking it off

    const r = hs.eventkit.createReminder({
        title: "Water the plants",
        dueDate: new Date(Date.now() + 3600000),
        alarmDates: [new Date(Date.now() + 3600000)]
    })
    // ...later
    r.update({ isCompleted: true })
