HSMQTTClient

Type

A connection to an MQTT broker, created by hs.mqtt.create().

The client does nothing until you call connect(). Messages for the topics you subscribe() to arrive as "message" events (see on()).

A connected client keeps working after you drop your reference to it, until you call disconnect() or destroy(), or Hammerspoon reloads its configuration. So does a client with listeners registered by on().

  • Example:
const client = hs.mqtt.create("mqtt://broker.local")
client.on("message", msg => console.log(msg.topic + ": " + msg.payload))
async function start() {
    await client.connect()
    await client.subscribe("home/+/temperature")
    await client.publish("home/office/light", "on")
}

on(event, listener) -> None

Register a listener for this client's events.

Listeners receive:

  • "connected": (), each time the client connects, including when it reconnects by itself
  • "disconnected": (reason), null when you called disconnect(), otherwise a description of why the connection was lost
  • "message": (message), an object with the message's topic, its payload decoded as UTF-8, its raw bytes (a Uint8Array), its qos, and whether it is retained and a duplicate

A client with listeners stays alive until you remove them or call destroy().

Declaration
on(event, listener) -> None
Parameters
Name Type Description
event string The event to listen for
listener function Called when the event occurs
Returns
None
Throws
Throws an Error on failure; wrap calls in try/catch to handle it.
Example
try {
    client.on("message", msg => console.log(msg.topic + ": " + msg.payload))
    client.on("disconnected", reason => console.log("Disconnected: " + reason))
} catch (err) {
    console.error(err.message)
}
