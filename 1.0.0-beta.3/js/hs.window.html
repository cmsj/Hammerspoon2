hs.window.forID(id) -> HSWindow

Get the window with the given ID

This is much faster than searching allWindows() for the ID, because it only asks the application that owns the window for its windows. Like allWindows(), this can find windows in native fullscreen and on other Spaces, with the same limitation.

hs.window.allWindows() -> HSWindow[]

Get all windows from all applications

This includes windows in native fullscreen and on other Spaces, with one limitation: macOS only reveals a window on a Space that isn't visible if its app has already handed that window to an accessibility client, e.g. because Hammerspoon listed it while its Space was visible. A window that no accessibility client has looked at since it was created is missing until its Space is next visible, unless it's its app's main or focused window, which are always included.

Declaration
hs.window.allWindows() -> HSWindow[]
Returns
HSWindow[]
An array of all windows
Example
const wins = hs.window.allWindows()
console.log(wins.length)

hs.window.moveToSpaceForID(id, space) -> Promise<void>

Moves the window with the given ID to another space, without switching to it. This is the same as an HSWindow's moveToSpace(), for windows you only have the ID of, such as those from HSSpace.windowIDs().

Declaration
hs.window.moveToSpaceForID(id, space) -> Promise<void>
Parameters
Name Type Description
id number The window's ID
space HSSpace The desktop to move the window to
Returns
Promise<void>
A Promise that resolves once the window is on that space, or rejects with the reason it couldn't be moved
Example
// Gather every window from the main screen's other desktops onto its current space
const screen = hs.screen.main()
const here = screen.currentSpace
for (const space of screen.spaces) {
    if (space.id === here.id || space.type !== "desktop") continue
    for (const id of space.windowIDs()) hs.window.moveToSpaceForID(id, here)
}
