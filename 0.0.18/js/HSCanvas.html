HSCanvas

Type

HSCanvas

A single canvas window: an absolutely-positioned, low-level drawing surface mirroring v1 Hammerspoon's hs.canvas. Elements are plain JS objects (matching v1's Lua tables) added with appendElements() and mutated in place with setElementAttribute()/elementAttribute(). Supports the same fill/stroke/ strokeAndFill/clip/build/skip action pipeline as v1, including the build+clip+reversePath technique used to punch holes in shapes (see hs.canvas.windowLevels/hs.canvas.windowBehaviors for the window-level/Spaces controls needed alongside this for overlay-style canvases).

Example

const c = hs.canvas.create({x: 100, y: 100, w: 200, h: 200})
c.appendElements([
    { type: "rectangle", action: "fill", fillColor: { red: 0.2, green: 0.5, blue: 0.9, alpha: 1 } }
])
c.show()

Properties

This type has no properties.

show(fadeInTime) -> HSCanvas

Show the canvas window, optionally fading it in

A fade goes from fully transparent up to the canvas's alpha(). Calling show(), hide() or destroy() while a fade is running replaces that fade, so showing a canvas that is fading out of hide() brings it back. A canvas that has been destroyed can't be shown again, even while it is still fading out.

hide(fadeOutTime) -> HSCanvas

Hide the canvas window, optionally fading it out (elements and window config are preserved while you keep a reference to it)

The canvas keeps its callbacks, and isShowing() stays true, until a fade-out has finished. Afterwards its alpha() is unchanged, so the next show() brings it back at the same opacity. Hiding a canvas that has been destroyed does nothing.

destroy(fadeOutTime) -> None

Destroy the canvas window and release its resources, optionally fading it out first

This releases the canvas's window, callbacks and elements (including any images they hold) straight away, rather than when the canvas is garbage collected. A destroyed canvas is finished with: from the moment destroy() is called, calling show(), appendElements(), insertElement(), assignElement(), replaceElements(), mouseCallback(), draggingCallback() or duplicate() on it throws an error, and imageFromCanvas() returns null.

Named destroy() rather than v1's delete() -- delete cannot be used as a JavaScriptCore-exported method name in this codebase's bridging layer.

minimumTextSize(source, text) -> object

The smallest size that can fully render a string of text, using the font attributes (textFont/textSize/textWeight/textDesign/textItalic) of an element, of an attributes object, or the defaults

Mirrors v1's hs.canvas:minimumTextSize([index], text). It can be called three ways:

  • minimumTextSize(index, text) measures with the font attributes of the element at index. Any element type works; attributes it doesn't set use their defaults.
  • minimumTextSize(attributes, text) measures with the font attributes in a plain object, so text can be measured before any element exists.
  • minimumTextSize(text) measures with the default font attributes (the system font at size 27, as a text element with no font attributes would be drawn).

Multi-line strings (separated by \n) are measured correctly -- the height covers every line and the width is the longest line's width, not a fixed single-line size.

Declaration
minimumTextSize(source, text) -> object
Parameters
Name Type Description
source JSValue The index of an element whose font attributes to measure with, an object of font attributes, or the string to measure (to use the default font attributes)
text JSValue The string to measure -- it doesn't need to match the element's own text. Omitted when source is the string
Returns
object
A {w, h} dictionary, or {} (with a warning logged) if index is out of bounds or the arguments are invalid
Example
// Size a text element to fit its text, before it's added to the canvas
const attributes = { textFont: "Menlo-Bold", textSize: 24 }
const size = c.minimumTextSize(attributes, "Hello\nWorld")
c.appendElements([{ type: "text", text: "Hello\nWorld", ...attributes,
                    frame: { x: 10, y: 10, w: size.w, h: size.h } }])

// Or measure with an existing element's font, or the default font
const fromElement = c.minimumTextSize(0, "Goodbye")
const withDefaults = c.minimumTextSize("Goodbye")

mouseCallback(callback) -> HSCanvas

Set the callback fired for tracked mouse events

Fires for elements with trackMouseDown/trackMouseUp/trackMouseEnterExit/ trackMouseMove/trackRightMouseDown/trackRightMouseUp set to true in their element dictionary, and for whole-canvas regions enabled via canvasMouseEvents() (delivered with id "_canvas"). mouseDown/mouseUp are the left button only; the right button (or a Ctrl-click, the standard macOS secondary click) is reported separately as rightMouseDown/rightMouseUp.

Declaration

Parameters

callback function A JavaScript function called with the canvas, the event name ("mouseDown"/"mouseUp"/"rightMouseDown"/"rightMouseUp"/"mouseEnter"/"mouseExit"/"mouseMove"), the tracked element's id, and the event's x/y coordinates
Returns
HSCanvas
Self for chaining
Throws
Throws an Error on failure; wrap calls in try/catch to handle it.
Example
c.appendElements([{ type: "circle", action: "fill", trackMouseDown: true, id: "dot" }])

c.appendElements([{ type: "rectangle", action: "fill", id: "button",
                    trackMouseUp: true, trackRightMouseDown: true }])

    if (message === "rightMouseDown") console.log("context menu for", id)
})
