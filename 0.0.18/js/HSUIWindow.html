HSUIWindow

Type

HSUIWindow

A custom window with declarative UI building

HSUIWindow allows you to create custom windows with a SwiftUI-like declarative syntax. Build interfaces using shapes, text, images, and layout containers.

** Note: ** A shown window stays on screen, with its callbacks, until it's hidden or destroyed, even if you don't keep a reference to it. Clicking the macOS close button only hides the window (firing the onHide() callback, if you have one configured) — it does not destroy the window while you hold a reference to it in JavaScript, so you can show it again. Call destroy() explicitly (for example from within an onHide() handler) if you want to release it sooner. See onShow(), onHide(), and onDestroy() below for the full set of lifecycle callbacks.

Building UI Elements

  • Shapes: rectangle(), circle()
  • Text: text(content)
  • Buttons: button(label) — uses SwiftUI's native Button for press-state feedback
  • Images: image(imageValue)
  • Video: video(videoValue)
  • Layout: vstack(), hstack(), zstack(), spacer()

Modifying Elements

  • Shape modifiers: fill(), stroke(), strokeWidth(), cornerRadius()
  • Text modifiers: font(), foregroundColor()
  • Image modifiers: resizable(), aspectRatio(mode)
  • Layout modifiers: frame(), opacity(), padding(), spacing()

Examples

Simple window with text and shapes:

hs.ui.window({x: 100, y: 100, w: 300, h: 200})
    .vstack()
        .spacing(10)
        .padding(20)
        .text("Dashboard")
            .font(HSFont.largeTitle())
            .foregroundColor("#FFFFFF")
        .rectangle()
            .fill("#4A90E2")
            .cornerRadius(10)
            .frame({w: "90%", h: 80})
    .end()
    .backgroundColor("#2C3E50")
    .show();

Window with image:

const img = HSImage.fromPath("~/Pictures/photo.jpg")
hs.ui.window({x: 100, y: 100, w: 400, h: 300})
    .vstack()
        .padding(20)
        .image(img)
            .resizable()
            .aspectRatio("fit")
            .frame({w: 360, h: 240})
    .end()
    .show();

onHide(callback) -> HSUIWindow

Set a callback to fire when the window is hidden

Fires when hide() is called, and when the user clicks the macOS close button — clicking that button only hides the window from Hammerspoon's perspective (see the class-level note above), so this is the callback that reacts to it. Does not fire when the window is destroyed via destroy() — use onDestroy() for that.

level(name) -> HSUIWindow

Set the window stacking level

Controls where this window sits in the macOS window hierarchy. Supported values:

  • "normal" — regular app window, sits with other app windows (default)
  • "floating" — floats above all normal windows
  • "screenSaver" — above the screen saver layer
  • "dock" — same level as the Dock
  • "status" — status bar level
  • "popUpMenu" — pop-up menu level

Can be called before or after show().

behavior(name) -> HSUIWindow

Set how the window behaves with Spaces, fullscreen apps and window cycling, from a single behavior name

The names (which map to NSWindow.CollectionBehavior) are:

  • "default" — the system default
  • "canJoinAllSpaces" — appears on every Space
  • "moveToActiveSpace" — moves to the active Space when shown
  • "managed" — participates in Spaces and Exposé (the default for normal windows)
  • "transient" — floats in Spaces and is hidden by Exposé
  • "stationary" — unaffected by Exposé
  • "participatesInCycle" / "ignoresCycle" — whether ⌘` cycles to the window
  • "fullScreenPrimary" / "fullScreenAuxiliary" / "fullScreenNone" — how the window relates to fullscreen apps; "fullScreenAuxiliary" lets it appear over another app's fullscreen Space
  • "fullScreenAllowsTiling" / "fullScreenDisallowsTiling" — whether it can be tiled in fullscreen

Use behaviorList() to combine several. An unknown name is logged and leaves the behavior unchanged. Can be called before or after show().

Declaration

Parameters

Returns
HSUIWindow
Self for chaining
Example

behaviorList(names) -> HSUIWindow

Set how the window behaves with Spaces, fullscreen apps and window cycling, from a combination of behavior names

See behavior() for the names. Some can't be combined, because AppKit treats them as mutually exclusive: "canJoinAllSpaces" with "moveToActiveSpace"; any two of "managed", "transient" and "stationary"; "participatesInCycle" with "ignoresCycle"; any two of the "fullScreen…" Primary/Auxiliary/None names; and "fullScreenAllowsTiling" with "fullScreenDisallowsTiling". Combining them throws, leaving the behavior unchanged. Unknown names are logged and ignored. Can be called before or after show().

Declaration
behaviorList(names) -> HSUIWindow
Parameters
Name Type Description
names string[] The behavior names to combine, or an empty array for the system default
Returns
HSUIWindow
Self for chaining
Throws

Example
// An alert that appears above everything, including fullscreen apps, on every Space
hs.ui.window({x: 100, y: 100, w: 400, h: 200})
    .level("screenSaver")
    .behaviorList(["canJoinAllSpaces", "fullScreenAuxiliary"])
    .text("Meeting starts now")
    .show()
