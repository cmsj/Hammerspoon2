    Namespace promises

    The promise-based equivalents of fs's *Sync functions, reachable as require('fs').promises and require('fs/promises'). WARNING: This module is an experiment to see if high levels of Node.js compatibility can be achieved with AI agents. Every function here runs its work synchronously (there is no background I/O thread pool in this engine) and wraps the result in an already-settled Promise, so await/.then() still work exactly as in Node, just without any real concurrency.
