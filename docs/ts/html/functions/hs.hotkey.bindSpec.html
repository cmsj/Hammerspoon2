    Function bindSpec

    • bindSpec(
          spec: any,
          mods: any,
          key: any,
          message: any,
          pressed: any,
          released: any,
          repeat: any,
      ): any

      Bind a hotkey from a single options object. Like hs.hotkey.bind()/create(), but also accepts a message and a repeat callback. message is available on any hotkey (not just ones created via bindSpec()) by setting .message directly on the returned object; see hs.hotkey's message property for exactly when it is shown.

      Parameters

      • spec: any

        An object with the following fields:

      • mods: any

        Modifier keys (e.g. ["cmd", "shift"])

      • key: any

        Key name or character (e.g. "h")

      • message: any

        [optional] A description shown as a toast when the hotkey fires

      • pressed: any

        [optional] Called when the hotkey is pressed

      • released: any

        [optional] Called when the hotkey is released

      • repeat: any

        [optional] Called repeatedly while the hotkey is held down

      Returns any

      A hotkey object, or null if binding failed
