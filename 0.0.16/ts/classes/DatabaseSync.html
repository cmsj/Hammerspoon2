    Class DatabaseSync

    A connection to a SQLite database, as Node's DatabaseSync from require('node:sqlite'). Every method runs synchronously. Databases are opened with foreign key constraints enforced and double-quoted string literals disabled, as in Node. Not implemented from Node: function(), aggregate(), loadExtension(), enableLoadExtension(), createSession(), applyChangeset(), backup(), createTagStore() and Symbol.dispose.

    • new DatabaseSync(path: string, options?: Record<string, any>): DatabaseSync

      Opens a SQLite database. Statements prepared on this database start with its readBigInts, returnArrays, allowBareNamedParameters and allowUnknownNamedParameters settings.

      Parameters

      • path: string

        The path of the database file, or ":memory:" for an in-memory database. A leading ~ is expanded to the home directory. Relative paths are relative to Hammerspoon's working directory, so use absolute paths.

      • Optionaloptions: Record<string, any>

        The options described above

      Returns DatabaseSync
