    Class StatementSync

    A prepared statement, as Node's StatementSync. Made by DatabaseSync.prepare(); it can't be constructed directly. Parameters are bound the same way for run(), get(), all() and iterate(): if the first argument is an object (other than a typed array), its properties are bound to named parameters (:name, @name or $name), and any remaining arguments are bound, in order, to

    JavaScript SQLite
    null, undefined NULL
    number REAL (stored as INTEGER in columns with INTEGER affinity)
    boolean INTEGER 1 or 0
    bigint INTEGER
    string TEXT
    typed array (e.g. Uint8Array) BLOB
    Results come back as null, numbers (or BigInts, see setReadBigInts()), strings and
    Uint8Arrays. An INTEGER too large to be a JS number throws, unless readBigInts is set.
