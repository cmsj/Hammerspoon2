hs.hotkey.followsKeyboardLayout

boolean
Whether hotkeys bound with a key name move to a different key when the keyboard layout changes, so that they stay on the key that types that character. Default is true. For example, a hotkey bound to `"w"` is on the key US-ANSI calls `W` while a US layout is active, and moves to the key US-ANSI calls `,` when you switch to Dvorak, since that's where Dvorak types `w`. Hotkeys bound with a numeric key code never move. When false, a hotkey stays on whichever key its name resolved to when it was created, as in Hammerspoon v1. Setting this back to true moves existing hotkeys to the current layout. If the new layout doesn't type a hotkey's character and the character has no US-ANSI position either, the hotkey stays where it is and a warning is logged. Avoid binding some hotkeys by key name and others by numeric key code with the same modifiers if you switch layouts. A hotkey that moves onto a key code another hotkey already holds can't be registered there, so it's disabled with an error logged, and it stays disabled until you call its `enable()` again, even after switching back.

hs.hotkey.bind(mods, key, onPressed, onReleased, onRepeat) -> HSHotkey

Bind a hotkey `cmd` / `command` / `⌘`, `shift` / `⇧`, `alt` / `option` / `⌥`, `ctrl` / `control` / `⌃`. through the current keyboard layout (see `hs.keycodes.map`), or a numeric virtual key code, which always means the same physical key
Declaration
hs.hotkey.bind(mods, key, onPressed, onReleased, onRepeat) -> HSHotkey
Parameters
Name Type Description
mods string[] An array of modifier key strings (e.g., `["cmd", "shift"]`). Supported names:
key any The key: a name or character (e.g. "a", "space", "return", "f1"), resolved
onPressed function A JavaScript function to call when the hotkey is pressed, or null for no callback
onReleased function A JavaScript function to call when the hotkey is released, or null/omitted for no callback
onRepeat function A JavaScript function to call repeatedly while the hotkey is held down, or null/omitted for no repeat
Returns
HSHotkey
A hotkey object, or null if binding failed (including when none of the callbacks is a function — at least one is required)
Notes
The hotkey stays bound until you disable it, even if you don't keep a reference to it.
Example
hs.hotkey.bind(["cmd","shift"], "h", () => {
    console.log("Hello!")
}, null, () => console.log("still held"))

hs.hotkey.createModal(mods, key) -> HSHotkeyModal

Create a new modal hotkey group, optionally entered via a trigger key combination
Declaration
hs.hotkey.createModal(mods, key) -> HSHotkeyModal
Parameters
Name Type Description
mods any Modifier keys for the trigger hotkey (e.g. ["cmd", "shift"]). Defaults to an empty array (no modifiers) when omitted
key any Key name or numeric key code for the trigger hotkey (e.g. "h"). Omit it, or pass null or an empty string, for a modal with no trigger
Returns
HSHotkeyModal
A modal object with bind(), enter(), exit(), destroy() methods, isActive property, and onEnter/onExit callbacks
Example
const m = hs.hotkey.createModal(['cmd'], 'h')
m.bind(['shift'], 'j', () => console.log('shift-j pressed'))
m.onEnter = () => console.log('modal entered')
m.onExit  = () => console.log('modal exited')
m.bind([], 'escape', () => m.exit())

// A modal with no trigger, entered and exited from your own code
const n = hs.hotkey.createModal()
n.bind([], 'escape', () => n.exit())
n.enter()
